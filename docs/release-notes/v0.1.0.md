**Preview release** — the first public build of BloodTrail Together, an unofficial two-player PCVR multiplayer mod for BloodTrail.

### Install
1. You do not need anything else: the installer adds [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) if you do not have it (an existing UE4SS and your other mods are kept).
2. Download **BloodTrailTogether-Setup-v0.1.0.exe** below and run it. It finds BloodTrail in your Steam libraries.
3. Click **Install**, start BloodTrail through Steam, press **F9** for the multiplayer window.
4. Host: **Create Session** and tell your friend the code. Friend: type the code and **Join Session**.

Windows SmartScreen may warn because the installer is not code-signed (More info → Run anyway). Checksums are in `SHA256SUMS.txt`.

### What works
- Online sessions through Unity Relay with a short join code — no VPN, no port forwarding.
- The other player's head and hands (simple shapes for now) with name tag and ping.
- The joiner follows the host into the same map (Sandbox and Arcade/Raid maps tested).
- Shared positional sounds; simulated player for testing alone.

### Not yet
- Full-body player model, players damaging each other, synced NPCs / gore / ragdolls.
- A complete two-headset session has not been tested yet — please report what happens!

Tested with BloodTrail build 18598125. Logs for bug reports: `BTVR\Binaries\Win64\ue4ss\UE4SS.log` and `ue4ss\Mods\BloodTrailTogether\BloodTrailTogether.log`.
