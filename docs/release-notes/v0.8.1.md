# BloodTrail Together 0.8.1

## Fixed
- **Character preview:** the model no longer sinks through the stage or flails. Floating above the map made the NPC's own "long fall" logic ragdoll it. The preview model is now a still mannequin (no game logic or physics) in a standing pose, with its feet kept on the stage.

## New, hidden pieces from the game files
- **ACCESSORY slot:** a headlamp, with or without its glass, made for the NPCs but never used.
- **FULL OUTFIT slot:** the game's unused test outfit (long sleeve and camo trousers).
- Looks saved by 0.8.0 still load; the new slots start empty.

## Not included
The game's files also list about 25 cult-member outfits (robes, pyjamas), but the game can't load them; they appear to be leftovers that were never packed. A beanie may not show while the test outfit or headlamp is worn.

## Tested
In the game's preview: the model stands on the stage while turning, and the headlamp, test outfit and sneakers show.
