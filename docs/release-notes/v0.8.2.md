# BloodTrail Together 0.8.2

## Faster
- **NPC list built once per frame:** NPC sync, voices, the smarter NPCs and the host check now share it. Before, up to five systems each rebuilt it every frame, reading every NPC's name.
- **Voice-line checks** run every 10 frames instead of every 6, so subtitles still appear within about 0.15 s.
- **Name-effect colours** update every 2nd frame. The letters still move every frame.
- **The F9 window** reuses its drawing surface instead of allocating a new full-window image 60 times a second.

## GitHub page
New README with an animated banner, animated buttons, badges and screenshots of the character menu.

## Tested
Unit tests pass. Ran in the game as host with live AI NPCs and a dressed simulated player for 80 seconds, with no errors.
